# 类别设计 Skill

## 触发方式

遇到以下场景时**必须**调用此技能，不要自行推断类别结构：

- **用户说**："新建一个类别"、"再建个 xxx 类别"、"需要添加新分类"
- **知识提取中**：发现新章节出现了不属于现有任何类别的新实体大类（如首次出现"丹药"、"阵法"等）
- **用户问**："人物词条应该包含什么信息"、"XXX 类别的写作规范是什么"
- **创建类别前**：调用 `new_category` 之前，必须先调用此技能获取对应的写作规范

**不触发**的场景：已有类别的常规知识提取不需要此技能。

## 类别体系

Wiki 类别分为三大基本类型 + 一个参考模板：

### 基本类型 ①：人物

具有自我意识与意志的个体。有自我意识的妖兽也算人物。

**需要 state 字段**：是

**写作规范**（传给 `new_category` 的 `writing_guide` 参数）：

```
人物词条需包含以下信息：
- 外貌描述：人物外貌，衣着等
- 身份地位：人物身份、势力归属等。与势力类别建立联系。
- 实力等级：境界修为、职业等级、种族等。与世界规则或设定图鉴建立联系。
- 性格：人物的性格表现，性格特点。
- 欲望与恐惧：人物的原动力，欲望。是人物行为和做出选择的动机。
- 持有物品信息：法宝、资源、修炼功法等。与设定图鉴建立联系。
- 情感与关系：与人物、势力的爱恨情仇。与人物、势力建立联系。
```

**subagent 正文推荐结构**：

```
## 基本信息
- 姓名、性别、年龄、身份、相关人物

## 外貌特征
身高、容貌、衣着、标志性特征

## 性格特点

## 修为境界 / 实力等级

## 背景经历
出身、重要经历、转折事件

## 近期事件（可选）
最近章节中的动态变化
```

---

### 基本类型 ②：势力

家族、门派、组织等。势力的状态不会因若干个人事件发生较大转移。

**需要 state 字段**：是

**写作规范**：

```
势力词条需包含以下信息：
- 势力架构：势力内的等级层级，高端战力、中坚战力等分布。与世界规则建立联系。
- 位置分布：势力所处位置及势力范围内的各类地图。与地图建立联系。
- 具体资源：重要资源如功法传承、矿脉、秘境、镇宗法宝、独门灵丹等。与设定图鉴和地图建立联系。
- 代表人物：势力内的代表人物，与主角接触过的重要人物或宗门高层。与人物建立联系。
- 意志体现：势力的意志、使命或阴谋。例如正道宗门的使命、邪道宗门的阴谋。
```

---

### 基本类型 ③：地图

故事中出现的城池、山川、建筑等地理位置。地图的状态不会因若干个人事件发生较大转移。

**需要 state 字段**：是（但注意：状态不因个人事件频繁变更）

**写作规范**：

```
地图词条需包含以下信息：
- 地理分布：地点的地理分布位置，内部包含的城镇，毗邻的禁地，内部的秘境等。与地图建立联系。
- 资源分布：地点内部的资源分布，如法宝、天材地宝等。与设定图鉴建立联系。
- 威胁存在：地点内的巨大威胁，如强大邪修、妖兽出没、险地等。往往蕴含着冲突。与人物、地图、设定图鉴建立联系。
- 势力分布：地图内分布的势力。与势力建立联系。
```

---

### 参考模板：设定图鉴（不是基本类型，是品类参考）

设定图鉴**不是一个具体类别**，而是一个设计参考。当出现以下实体大类时，每个大类应独立建为一个类别：

| 可展开的类别 | 示例 | 需要 state |
|-------------|------|-----------|
| **功法** | 七步拳、不败血体、霸王拳 | 否 |
| **神通** | 真空剑气、九臂霸王拳 | 否 |
| **法宝** | 储物戒指、毒巨子、铁星弩 | 否 |
| **丹药** | 衍生丹、凝气丹 | 否 |
| **符箓** | 神行符、金刚符 | 否 |
| **阵法** | 聚灵阵、杀阵 | 否 |
| **妖兽** | 四臂妖熊、黑纹妖蟒 | 否 |
| **天材地宝** | 千年灵芝、玄铁 | 否 |

**写作规范**（所有设定图鉴展开类别共用）：

```
xxx词条需包含以下信息：
- 外观描述：静态外观与动态奇观。如功法无外观但有施法特效，丹药无施法特效但有外观。
- 功能特点：具体特点描述，功效等。因种类而异。
- 持有信息：物品是否有主，出现位置或归属等。与人物、势力、地图建立联系。
```

## 类别创建流程

```
1. 分析章节内容，判断新实体属于哪种类型
2. 调用此技能获取对应类型的 writing_guide
3. 调用 new_category 创建类别
   - name = 类别名
   - description = 简明描述
   - writing_guide = 从本技能复制的写作规范
   - has_state = 按类型设定（人物/势力/地图=true，设定图鉴类=false）
```

**示例**：创建"丹药"类别

```
new_category(
    name="丹药",
    description="故事中出现的各类丹药，如衍生丹、凝气丹等",
    writing_guide="丹药词条需包含以下信息：\n- 外观描述...\n- 功能特点...\n- 持有信息...",
    has_state=False
)
```

## ⚠️ 类别设计强制规则（重要！）

LLM 在创建类别时**容易将所有物品类实体一股脑归入"宝物"类**，必须遵守以下规则：

### 规则一：优先创建具体类别

遇到非人物/势力/地图的实体大类时，**必须首先考虑**从设定图鉴模板展开为具体类别：

| 优先创建的类别 | 适用实体示例 |
|--------------|------------|
| **法宝** | 储物戒指、寒焱鼎、铁星弩、毒巨子 |
| **丹药** | 衍生丹、凝气丹、合神丹、化灵丹 |
| **灵草** | 千年灵芝、百善灵果 |
| **功法** | 不败血体、七步拳、霸王拳 |
| **神通** | 真空剑气、九臂霸王拳 |
| **符箓** | 神行符、金刚符 |
| **阵法** | 聚灵阵、杀阵 |
| **妖兽** | 四臂妖熊、黑纹妖蟒、骨月妖狼 |
| **矿物宝石** | 玄铁、精金、寒玉 |
| **阴邪之物** | 血翼之心、婴丹 |

**不得**将上述实体归入"宝物"等泛用类别。

### 规则二：泛用类别的使用限制

可以创建**宝物、世界观**等泛用类别，但**必须满足以下条件**：

1. **只有无法归入上述具体类别的实体**才能放入泛用类别
2. 创建泛用类别时，`description` **必须写明兜底语义**，例如：
   - `"无法归入法宝/丹药/灵草等具体类别的特殊物品"`
   - `"不属于人物/势力/地图/设定图鉴的世界观概念"`
3. 泛用类别的 `writing_guide` 中必须包含"此类别为兜底类别，只有其他具体类别无法容纳的实体才归入此类"

### 规则三：禁止创建"宝物"类别，使用"世界观"兜底

- ❌ **禁止创建「宝物」类别**。系统层面已拦截，创建会直接报错。
- ✅ 如果某个实体确实无法归入任何已有类别（人物/势力/地图/法宝/丹药/灵草/功法等），
    使用 **「世界观」** 类别作为兜底。
- ✅ 创建「世界观」类别时，`description` **必须写明**：
  `"其他类别无法包含的词条，如特殊能量、抽象概念、未分类物品等"`
- ✅ 已有类别直接复用，不需重建

### 规则四：查全所有分页再判断

- `wiki_list` 返回的结果可能有多页（如 `第 1/3 页`），**必须逐页查完**再判断某词条是否存在
- ❌ 只看第 1 页就说"词条不存在" → 漏掉了第 2/3 页的词条
- ✅ 先翻完所有分页，确认真的不存在，才考虑新建

## 注意事项

- `new_category` 的 `description` 参数是类别的简短说明（会写进 index.md 的 description 字段）
- `new_category` 的 `writing_guide` 参数是写作规范正文（会写进 index.md 的 ## 写作规范 章节）
- 设定图鉴参考模板**不直接作为类别**，而是要展开为具体类别（如"法宝"、"丹药"）
- 已有类别不需要重建
- 如果新类别不属于以上任何一种，根据实际情况自定义

## 词条命名约定

- **`词条名（别名）`** — 括号 `（）` 内为有效同义词/别名，两个都作为关键词匹配
  - 例：`叶寒（寒叔）`，搜索"叶寒"或"寒叔"均能匹配到该词条
- **`词条名【说明】`** — 括号 `【】` 内仅为消歧义说明，不作为关键词
  - 例：`叶家【紫玉大陆】`，只匹配"叶家"
- **`type` 字段必须用中文**，且与所在文件夹名一致
  - 例：人物类词条 → `type: 人物`（而非 `type: character`）
