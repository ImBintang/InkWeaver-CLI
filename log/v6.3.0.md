## 结构性拆分

### Muse.py 子包化（1402 行 → 4 模块 + 1 入口）

原 `Muse.py` 同时承载 `ReviewSession`、`MuseAgent`（700+ 行，含工具分发和版本硬切逻辑）、`MuseWorkflow`（650+ 行，四步写作状态机）三个核心类，现拆为：

| 文件 | 职责 | 行数估算 |
|------|------|---------|
| `muse/__init__.py` | 包入口，导出 `ReviewSession` / `MuseAgent` / `MuseWorkflow` | ~10 |
| `muse/review_session.py` | `ReviewSession` 数据类（审阅状态管理、评分逻辑） | ~60 |
| `muse/agent.py` | `MuseAgent`（工具定义、工具分发、版本硬切 `_at_ceiling` 辅助方法） | ~500 |
| `muse/workflow.py` | `MuseWorkflow`（四步写作状态机、审阅循环、token 统计） | ~650 |
| `Muse.py` | 向后兼容入口（re-export），老代码 `from Muse import ...` 无需修改 | ~6 |

**验证**：`from Muse import ...` 与 `from muse import ...` 19 个模块全量导入测试通过。

### cli/core 统一

消除 `cli.py` 与 `core/` 包之间的重复实现和循环导入：

- `cli.py` 的 `SessionLogger` 现在是 `core.session.SessionLogger` 的 re-export（同一对象，`SessionLogger is core_SessionLogger → True`）
- `CLI` 类保留为向后兼容包装
- `core/io.py` 移除 `from cli import CLI` 循环依赖，`print_plan` 逻辑内联至 `IOChannel`

### 共享 Subagent 工具提取

新增 `tools/shared_subagent_tools.py`，将 `knowledge_task.py`、`plot_task.py`、`review.py` 三处重复的 ~82 行工具定义列表和 `run_subagent_loop` 分发循环提取为共享模块。

## 安全修复

### 路径遍历防护

**`tools/editor.py`** — `resolve_path()` 增加路径遍历校验：

```python
# 禁止路径分隔符或上级目录引用
for param, param_name in [(name, "name"), (category, "category")]:
    if param and ("/" in param or "\\" in param or ".." in param):
        raise ValueError(...)

# 解析后 containment 检查
if not str(resolved).startswith(str(workspace.resolve())):
    raise ValueError("非法路径：超出工作区范围")
```

**`server/router/books.py`** — 新增 `_safe_book_path()` 白名单校验：

```python
_NAME_RE = re.compile(r"^[a-zA-Z0-9_\-\u4e00-\u9fff]+$")
# 不匹配则拒绝；解析后再做 containment 检查
```
