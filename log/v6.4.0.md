# v6.4.0 — 鉴知对话会话管理系统

> 日期：2026-07-30 | 状态：**已完成**

---

## 一、版本定位

将 v6.1 遗留的"静态会话管理 UI 壳"落地为完整的多会话系统。每本书支持多个独立会话，用户可在左侧栏创建 / 切换 / 重命名 / 归档 / 删除会话，所有消息持久化为 JSONL 文件，会话切换期间输入区锁定， pending_confirm 自动清除。

---

## 二、设计要点

### 2.1 Grilling 修正项

| 修正点 | 改前 | 改后 |
|--------|------|------|
| 消息持久化 | JSON 数组全量重写 | **JSONL 真 append**，meta 行可重写 |
| 写盘时机 | 每次 token 触发重写 | **task_done 批量落盘**，buffer 累积 |
| activate 竞态 | 无任何保护 | **前端 block 输入区 + sidebar pointer-events:none** |
| pending_confirm 恢复 | 卡片原样恢复（agent runtime 已丢失） | **activate 时清除**，计划不暂存 |
| 搜索 | 后端全文端点 | **前端本地过滤** index.json |
| 50+ 会话性能 | v-for 全量渲染 | **RecycleScroller 虚拟滚动** |
| 文件崩溃 | JSON 损坏整个 session 不可用 | **trim 最后损坏行**，丢失 ≤ 1 条消息 |
| Compact 语义 | 消息被清除 | **保留全部 + meta.compact_summary 更新** |
| 消息上限 | 无 | **cap=500**，LLM context 仍可用摘要 + 最近 N 条 |
| LLM 命名 | 第二轮独立调用 | **首轮 response 内嵌 name 字段**，零延迟 |

### 2.2 存储协议 (JSONL)

```
{"type":"meta","id":"sess_xxx","name":"...","created_at":"...","updated_at":"...",
 "archived":false,"compact_summary":"...","pending_confirm":null,
 "message_count":0,"first_user_message":"...","cap":500}
{"type":"message","id":1,"role":"user","content":"...","timestamp":1722326520}
{"type":"message","id":2,"role":"assistant","content":"...","timestamp":1722326580}
{"type":"usage","input_tokens":1205,"output_tokens":492,"model":"gpt-4o","timestamp":...}
```

- 首行 `meta` 随每次 task_done 重写（seek(0)+truncate）
- 消息行 append 写入
- 损坏的最后一行自动 trim（行解析失败则丢弃）

| 方法 | 职责 |

| `generate_id()` | `sess_<YYYYMMDD>_<HHMMSS>_<5hex>` |

### 3.3 HTTP API

**文件**：`InkWeaver-CLI/server/router/sessions.py`

| 方法 | 路径 | 行为 |
|------|------|------|
| `GET` | `/api/books/{book}/sessions` | 返回 index.json |
| `POST` | `/api/books/{book}/sessions` | 创建 + 自动 activate |
| `GET` | `/api/books/{book}/sessions/{sid}` | 完整 JSONL messages |
| `PATCH` | `/api/books/{book}/sessions/{sid}` | 重命名 / 归档 |

### 3.4 现有 API 改造

**文件**：`InkWeaver-CLI/server/router/chat.py`

| API | 改造 |
|-----|------|
| `POST /api/chat/messages` | + `?session_id=xxx`，**cap 403 校验** |
| `POST /api/chat/compact` | 仅更新 `meta.compact_summary`，**不清 messages** |
| `POST /api/chat/clear` | 保留 meta + compact_summary，**truncate 到首行** |
| `POST /api/chat/confirm` | 同时清 session 的 pending_confirm |
| `_run_jianzhi()` | emit `TASK_DONE` 携带 session_id |

### 3.5 SSE 批量写盘

**文件**：`InkWeaver-CLI/server/sse.py`

```
_msg_buffers[session_id] = []

on token/output → _msg_buffers[sid].append(msg)
on confirm_request → save_pending_confirm immediately
on task_done → _flush_buffer(sid) → add_message() per item
```
